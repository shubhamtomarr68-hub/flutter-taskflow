# Contributing

This is a portfolio project. Keep pull requests small.

1. Branch from `main`.
2. Run:

```bash
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
```

3. Do not add a fake backend or claim the app syncs.
4. Do not commit API keys or `local.properties`.

Commit prefixes: `feat`, `fix`, `docs`, `test`, `refactor`.
